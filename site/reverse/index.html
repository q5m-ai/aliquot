Test a predecessor outside the scan

Enter any positive integer m (up to 1,000 digits). It becomes a selectable candidate only after an exact check that s(m) equals the current frontier. Factorization has a 2,000,000-work-unit budget; exhaustion is unresolved, never a rejection or a probable-prime shortcut.

What does this search establish?

The sieve checks every positive source m up to the displayed bound using exact integer divisor sums. For n > 1, a predecessor m must be composite. It has a proper divisor d ≥ √m, so n = s(m) ≥ 1 + d, giving m ≤ (n − 1)². A search covering that ceiling is complete; otherwise, “none found” applies only to the checked range.

For target 0, the only predecessor is 1. For target 1, the predecessors are all primes: every finite search is partial. Zero is never a predecessor, because s(0) is undefined.

There is no preset backward-depth limit. The grid displays the latest five chosen nodes and eight candidates per page; the full chosen chain stays in this tab and can be downloaded as exact decimal strings. Reloading starts a new chain. Search bounds and browser resources still apply.

A backward path is not a proof of an unbounded forward orbit. Extending it changes the earliest starting value. Finite gains and an unbounded collection of ancestors are not the same as one unbounded forward orbit.
