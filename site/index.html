An open research question

Start with a positive integer and repeatedly sum its proper positive divisors. Does every sequence eventually reach 1 and terminate, or settle into a cycle? This is the aliquot sequence conjecture.

This q5m research project explores possible paths to a proof or disproof. The animation is an experiment, not a proof: a growing finite prefix is not evidence of divergence, and a calculation limit is not a mathematical conclusion.

The explorer uses exact BigInt arithmetic with no 10¹⁵ ceiling. Browser resource budgets are 1,000 decimal digits per term and 2,000,000 factorization work units per step; difficult factorizations can stop well below those sizes. A stopped calculation is unresolved, not divergent. Graph coordinates are approximate; the displayed integer values are exact. Local research and independent verification run in Python. It displays the latest 180 terms. We extend terminated sequences with 0 → 0 for visualization only; s(0) is not defined by the positive-divisor formula. Amber marks the first zero, perfect number, or repeated value encountered in this run—not a new mathematical discovery.
