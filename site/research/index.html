Notation s, σ, T, and escape

The aliquot sum s(n) adds the positive divisors of n smaller than n itself. Repeatedly applying s produces an aliquot sequence; iteration stops at zero. Superscript 2 on s or T means applying the function twice, not squaring its value. All number-theoretic variables are integers unless stated otherwise.

n₀ is positive; while nₖ > 0, nₖ₊₁ = s(nₖ) is the sum of its proper positive divisors.
σ(n) = n + s(n); T(u) = 2σ(u) − u.
ℙ = the primes; P(n) = the prime divisors of n; P(1) = ∅.
E means an infinite positive orbit with no repeated terms.

A number is deficient if the next term is smaller, abundant if it is larger, and perfect if it is unchanged. An escaping orbit is an infinite sequence with no repeated terms. Its values tend to infinity, but individual steps can decrease.

  1. 22 Oct 2026Note 07 · Proposition O

    Deficient recovery

    A decreasing step does not imply a net loss over two steps. For every fixed deficient core D > 1 (so s(D) < D) and every real G > 1, infinitely many primes p coprime to D (sharing no prime factor with D) give:

    n = Dp, s(n) < n, and s(s(n)) > Gn.

    The first inequality says the sequence decreases from n. The second says that after one more step it exceeds G times its starting value. G can be as large as desired, with a suitable choice of starting number.

    For a prime p not dividing D, s(Dp) = s(D)p + σ(D). A prime progression forces this next term to contain a divisor with a large proper-divisor sum, which guarantees the rebound. The argument uses Dirichlet’s theorem and Euler-product divergence.

    Example: 844 → 640 → 890; this orbit later reaches zero. No repeated recovery on one seed is proved: the recovered term need not satisfy the entry conditions for another block.

    Recovery into a perfect-core class

    A refinement lands above any prescribed gain in a proper multiple r of perfect 28, guaranteeing one further growing step:

    28 divides r and r > 28, so s(r) > r.

    The recovered term is not itself perfect, and is outside this construction’s entry family.

  2. 22 Oct 2026Note 07 · Propositions P–Q

    Periodic prime-cofactor schedules

    Can an orbit escape by repeatedly cycling through a fixed list of factorization shapes? Fix cores D₀, …, DL−1 > 1 in a repeating schedule. A core is the chosen fixed factor Dᵢ in n = Dᵢp. At every source, the remaining cofactor p must be prime and coprime to its core.

    nⱼL₊ᵢ = DᵢpⱼL₊ᵢ for 0 ≤ i < L, with prime pⱼL₊ᵢ coprime to Dᵢ.
    An infinite positive tail of this form satisfies nₖ₊L = nₖ.

    If these shapes persist forever, the actual values must repeat too: after L steps, the sequence returns to the same number. Thus this mechanism can describe a cycle, but not escape.

    Composing one scheduled block gives an affine rule p′ = Ap + B for the checkpoint primes. Expanding rules either exhaust a finite divisibility reserve or force a later cofactor to be composite; contracting rules can describe a genuine cycle.

    Deficient steps are allowed. Composite cofactors and nonperiodic schedules are not excluded by this result.

    Nonperiodic switching · Proposition Q

    With finitely many fixed cores Dᵢ ≥ 2 and prime, coprime cofactors at every source, an escaping itinerary requires an expansive cycle C in its recurrent transition graph:

    Escape requires a recurrent-graph cycle C whose source-core ratios s(Dᵢ)/Dᵢ multiply to more than 1.

    The graph records which core can follow which, keeping only transitions used infinitely often. Each factor s(Dᵢ)/Dᵢ is the slope contributed by a source core; their product measures expansion around a cycle. If every cycle is nonexpansive, the prime-cofactor itinerary cannot escape.

    Necessary, not sufficient. The cycle need not occur consecutively or be repeatable by the actual orbit. This leaves nonperiodic switching with expansive cycles unresolved.

  3. 22 Oct 2026Note 06 · Propositions L–N

    Composite factor transport

    Tracking factors separately would simplify iteration, but updating two factors independently generally gives the wrong answer. Define T(u) = 2σ(u) − u, where σ sums all positive divisors. For coprime v, w > 1, the correction is exact:

    T(T(vw)) = T(v)T(w) + 2[s(T(vw)) − s(v)s(w)].

    The first term updates v and w separately. The bracket is the discrepancy: it depends on the divisor sum of the combined intermediate value T(vw), not just on the two original factors. This identifies the additional arithmetic information a factor-based construction must control.

    The connection to aliquot iteration is s(6u) = 6T(u), which requires gcd(u, 6) = 1 at each source. The correction does not guarantee renewal.

    A conditional supplier handoff
    29274 → 43302 → 55770. Their cofactors follow 7·17·41 → 7·1031 → 13²·5·11 under T.

    A guarded formula replaces suppliers with composite output blocks. The output does not regenerate the input factorization or the next prime-bridge condition.

  4. 22 Oct 2026Note 07 · Supporting constraint

    Large-prime supply bound

    How many large prime factors are needed to make a number abundant? Write n = dr, where d contains the complete prime-power factors with primes at most B ≥ 2. Let t count the distinct primes in r, all greater than B. For real 0 < ε < 2:

    If σ(d)/d ≤ 2 − ε and n is abundant, then (2 − ε)(1 + 1/B)ᵗ > 2.

    The ratio σ(n)/n measures the sum of all divisors relative to n; abundance means this ratio exceeds 2. If the small-prime part falls short by at least ε, the large-prime factors must collectively make up the difference. Each contributes less than 1 + 1/B, giving the displayed necessary inequality.

    For example, if σ(d)/d ≤ 3/2 and B = 10, at least four distinct primes above 10 are needed: (3/2)(11/10)³ < 2. Four is only a necessary count, not a guarantee of abundance.

    A fixed deficiency margin is essential. Perfect or abundant small-prime parts avoid this hypothesis. Prime-support escape does not supply it.

  5. 21 Oct 2026Note 05 · Proposition K

    Fixed prime-support finiteness

    Can an orbit grow forever using only a fixed collection of primes, with their exponents increasing? P(n) is the set of prime divisors of n, with P(1) = ∅. For any prescribed finite prime set S, only finitely many adjacent pairs n, s(n) use primes from S alone:

    For each finite prime set S, only finitely many n > 1 have all prime factors of both n and s(n) in S.
    If E holds, infinitely many distinct primes occur. Whether any such seed exists remains open.

    An escaping orbit never repeats a value, so it eventually leaves every finite collection of admissible pairs. Consequently, no fixed finite set of primes can support the whole orbit: infinitely many distinct primes must appear. The proof applies the classical S-unit finiteness theorem to the divisor-sum identity.

    Conditional on escape; this does not force a new prime at every step, or a decrease when large primes appear. It constrains an escaping orbit without establishing that one exists.

    From source values to orbit indices
    If E holds, then for each finite prime set S, only finitely many adjacent orbit pairs are supported on S.

    Nonrepetition is essential: finitely many source values can otherwise recur at infinitely many indices.
