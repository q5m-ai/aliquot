For a target n > 1, every solution of s(m) = n satisfies m ≤ (n − 1)²: m is composite and has a proper divisor d ≥ √m, so n ≥ 1 + d. The initial dataset’s independent source sieve covers 1–1,000,000, enough for every starting target from 2 through 1,000. Larger reached values can have partial inverse coverage; their cards report it explicitly. Newly added nodes have no absence claim until a completed search covers their ceiling; a smaller search is partial. In particular, all sources through 2,601 are checked for 52. For 1 the predecessor set is infinite: exactly all primes. For 0 the only predecessor is 1; s(0) is undefined, so there is no outgoing arrow from 0.

The public dataset is reproducibly generated by exact Python integer factorization, with 64 steps per starting value, a 1,000,000 source-value cap, and 2,000,000 factorization work units per call. The largest reached value is 1,895,712. Eleven frontiers exceed the source-value cap, leaving 30 starting orbits unresolved; these are computation limits, not claims about their eventual fate. Live forward additions use exact BigInt arithmetic: at most 64 new steps per action, 1,000 digits per drawn node, and 2,000,000 factorization work units per step.
