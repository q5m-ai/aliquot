Leaves, patterns & exact bounds

A displayed leaf has no incoming arrow in this graph. It need not lack a predecessor elsewhere: 12 is a displayed leaf, but 121 → 12 is outside these starting orbits. A pink ring means the stronger statement: no positive predecessor exists (an untouchable number). Among starts 1–100, these are exactly 2, 5, 52, 88, and 96.

For a target n > 1, every solution of s(m) = n satisfies m ≤ (n − 1)²: m is composite and has a proper divisor d ≥ √m, so n ≥ 1 + d. The independent source sieve covers 1–100,000, enough to cover this ceiling for every displayed target other than 1. In particular, all sources through 2,601 are checked for 52. For 1 the predecessor set is infinite: exactly all primes. For 0 the only predecessor is 1; s(0) is undefined, so there is no outgoing arrow from 0.

Each positive starting integer from 1 through 100 is included, not just the leaves. Shared values and arrows are drawn once; values above 100 remain visible when an orbit reaches them. All these orbits are resolved: 96 starts terminate at 0, 1–100 contains three starts reaching 6 (6, 25, 95), and 28 is already fixed. The self-loops at 6 and 28 are genuine cycles.

Look for the prime fan into 1, shared tails, and the contrast between abundant steps and the small perfect-number components. The flow is left-to-right on wide screens and top-to-bottom on narrow screens. Larger dots have more incoming arrows in this graph, not necessarily more global predecessors. Placement within a layer is only layout. Selection highlights the forward orbit, not all ancestors. Closing the details card leaves the highlighted path visible; All orbits clears it.

The public dataset is reproducibly generated by exact Python integer factorization, with 64 steps per starting value, a 1,000,000 source-value cap, and 2,000,000 factorization work units per call. None of these forward limits is reached here: the largest value is 259. A separate additive divisor sieve checks predecessors; tests independently verify it by divisor-pair enumeration. Layout never determines arithmetic or primality. Integer values in the download are decimal strings.

This finite graph suggests questions, not a proof of the aliquot conjecture or evidence of divergence. The 45 displayed leaves describe only this chosen family of starts; the five no-predecessor certificates are global statements for those individual targets.
