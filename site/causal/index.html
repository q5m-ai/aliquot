A causal view of aliquot sequences

Thought experiment · Numbers as space, iteration as time

What if an aliquot sequence were a history, different histories could merge, and recurrence marked the end of a branch? This perspective makes the structure easier to discuss. It does not supply a new law governing the arithmetic.

A reformulation, not a solution. No proof, disproof, divergent sequence, or historical novelty is claimed. “Universe” and “death” are metaphors, not a physical model.

1. A branch as a history

For a positive starting number, one step replaces the number by the sum of its proper positive divisors:

While nₖ > 0, nₖ₊₁ = s(nₖ), the sum of the positive divisors smaller than nₖ.

Think of the number as a spatial coordinate and the index as elapsed time. An event on a chosen trajectory has coordinates (t₀ + k, nₖ). No spatial metric, speed limit, or physical conservation law is assumed.

The symbol ≺ (\prec in LaTeX) means strict causal precedence, not numerical inequality. Neighboring entries below are one-step links; precedence also relates earlier events to later events along a history. Shared number labels represent merges in this acyclic example:

121 ≺ 12 ≺ 16 ≺ 15 ≺ 9 ≺ 4 ≺ 3 ≺ 1 ≺ 0; 26 ≺ 16; 30 ≺ 42 ≺ 54 ≺ 66 ≺ 78 ≺ 90 ≺ 144 ≺ 259; 259 ≺ 45 ≺ 33 ≺ 15.

The branch from 30 rises to 259, then joins the shared tail at 15. Multiple pasts are possible, but each number has just one successor. Zero is terminal: s(0) is undefined, not a self-loop. Inspect the value graph at 16.

2. Different lead-ins, one clock

If branch i reaches a chosen merge at local index Lᵢ, synchronize it by shifting its time origin:

tᵢ(k) = k − Lᵢ. Every branch reaches the chosen merge at time zero.

For a merge at 16, write each event as (time, number):

(−2, 121) ≺ (−1, 12) ≺ (0, 16) ≺ (1, 15); (−1, 26) ≺ (0, 16).

The 121 branch starts one tick earlier than the 26 branch. If all starts were forced to time zero, these arrivals would instead be the same place at different times, not one merge event.

What is T?

For a component known to reach a terminal node D, we can set death at time zero and count backward. The clock called T in this thought experiment is written Tclock here:

T_clock(v) = −d(v, D), where d is the number of remaining one-step links to D; T_clock(D) = 0.
3 ≺ 1 ≺ 0 has clock values −2, −1, 0.

Every one-step link advances this clock by one. Moving the origin from a merge to death just adds a constant. For cycle endpoints, use the contracted graph described below.

This signed clock is not the nonnegative orbit length T(n) on Lengths, nor the cofactor map T(u) = 2σ(u) − u on Research. It is defined here only when a finite endpoint exists. Assuming such a clock for every branch would assume the conjecture, not prove it.

3. What if recurrence means death?

On an individual trajectory, stop at zero or at the first repeated value. Call the number of steps to that event τ(n₀), with τ(n₀) = ∞ if neither event ever occurs. A repeated visit is a distinct terminal event; it must not be identified with its earlier occurrence.

Otherwise the amicable pair 220, 284 would give 220 ≺ 284 ≺ 220, violating a strict causal order. A perfect number would give the equally forbidden 6 ≺ 6.

First-repeat death depends on history. Separately, these two trajectories stop as follows. Subscripts label local event indices; † marks the terminal visit:

A: 220 at index 0 ≺ 284 at index 1 ≺ 220 at index 2, then death. B: 562 at index 0 ≺ 284 at index 1 ≺ 220 at index 2 ≺ 284 at index 3, then death.

Both reach 284 at index 1. But the next 220 is a repeat for A and new for B. These are separate histories, not a merged memoryless state. To preserve this stopping rule, retain enough history, for example a state (n, S) with S the set of previously visited values. Matching coordinates alone need not mean matching states.

4. One terminal node for each cycle

For genuine merges with a shared future, use a different convention: contract every positive cycle C into a terminal node DC. Remove its internal cycle edges, including perfect-number self-loops. Let D₀ denote zero. A cycle node labels a whole cycle, not a single numerical spatial coordinate.

95 ≺ 25 ≺ D_{6}; 119 ≺ 25; 143 ≺ 25; 562 ≺ D_{220,284}.

This is death at cycle entry, not at first repetition. A seed already in a cycle is already at its terminal node. The two conventions agree on mortality, not on death time. Contracting cycles is a mathematical definition, not an algorithm for discovering unknown cycles.

Take strict forward reachability in this graph as ≺. It is acyclic and transitive; each interval between comparable nodes contains only finitely many events. This gives a locally finite strict partial order, the causal-set structure intended here. It need not have any particular spacetime geometry.

5. The conjecture becomes universal mortality

For every positive starting integer n₀, the first-zero-or-repeat lifetime τ(n₀) is finite.

Equivalently, every forward chain in the cycle-contracted graph reaches a death node. A counterexample would be one immortal branch: an infinite positive orbit with no repeated values.

This is a statement about each branch’s future, not about the entire graph being finite. Infinitely many prime starts feed the same finite tail:

For every prime p, p ≺ 1 ≺ D₀.

6. What we actually know

Merges preserve eventual fate

Once two trajectories reach the same number, their subsequent number sequences agree. Both are mortal or both are immortal. Their first-repeat detection times can still differ because their pasts differ.

A bounded branch must die

An immortal branch cannot repeat any integer. There are only finitely many positive integers below each fixed bound, so eventually it leaves that entire bounded region:

If τ(n₀) is infinite, then nₖ tends to infinity.

This is stronger than having arbitrarily high peaks, but it does not require monotonic growth. Individual steps may decrease.

Arbitrarily long growth is not immortality

Lenstra’s classical construction gives an arbitrarily long finite increasing prefix, with a suitable seed for each requested length:

For every finite L, some seed has n₀ < n₁ < … < nL. A seed for every length does not give one seed that works for every length.

These are prefixes of the original number sequence, before cycle contraction. They do not certify an immortal branch. Construction and attribution.

Fixed prime support cannot sustain escape

Research note 05 gives an argument using the classical S-unit finiteness theorem: for each fixed finite set of primes, only finitely many adjacent pairs n, s(n), with n > 1, use those primes alone. Consequently, any immortal orbit must satisfy:

Immortality implies that the largest prime factor of nₖnₖ₊₁ tends to infinity.

Here P⁺ is the largest prime factor. Eventually every adjacent pair contains a prime exceeding any prescribed bound. This does not assert a previously unseen prime at every step, or termwise prime-factor growth. Changing prime support is not a contradiction. Argument and limits; attribution audit. Historical novelty is unverified; software tests do not verify this theorem.

Finite calculations leave unresolved branches

276 ≺ 396 ≺ 696 ≺ 1104 ≺ 1872 ≺ 3770; 306 ≺ 396.

The displayed 276 prefix has five verified steps, not a measured full lifetime. The shared future remains unresolved: the prefix proves neither eventual death nor immortality. A computation budget failure is also unresolved, never evidence of divergence. Inspect this branch.

The project’s local growth, factor-transport, and recovery arguments likewise do not yet regenerate their own entry conditions forever. Finite recovery is not a self-sustaining mechanism. Result map and exact failures.

7. A useful picture, not yet a solution strategy

The causal language organizes shared futures, history-dependent stopping, and possible escape. Much of the construction is standard functional-graph reasoning. Renaming recurrence as death adds no arithmetic constraint.

Acyclic does not mean terminating. An infinite chain is consistent with a causal set:

e₀ ≺ e₁ ≺ e₂ ≺ … is a possible infinite causal chain.

Nor can the clock settle the issue: proving a finite death-anchored Tclock for every starting value would essentially prove the original conjecture. Defining it as “steps remaining” does not independently establish that those steps are finite.

  • To prove universal mortality: find an additional arithmetic reason every branch ends, such as an independently defined nonnegative integer quantity that decreases along nonterminal steps or suitably controlled finite checkpoints.
  • To disprove it: exhibit one seed with a rigorously perpetual nonrepeating future, perhaps through a self-renewing arithmetic construction. No finite prefix is enough.

The thought experiment is worth keeping as a map of the problem. Whether aliquot arithmetic permits an immortal branch remains open.
